## 使用

1. 运行原来的一键启动；板卡连接后，在 PC 发起整景或矩形任务。
2. 地块台账中绘制并保存有效的多边形。对应行点击“显示到 DP”。
3. DP 保留上方任务卡，下方显示所选地块的覆盖率、主要类别、主类/混杂/低置信占比，以及各类面积和占比。地图上用黄色边界显示地块。
4. 点击“DP 显示任务统计”可切回本次整景/矩形统计。
5. 打开 http://127.0.0.1:8765/dp ，点击“开始镜像”。点击“全屏”后可用 OBS 或 Windows 录屏录制该网页窗口。

镜像读取板端实际显示帧缓冲，1920×1080；RGB565 压缩传输，页面目标每秒一帧。它适合演示界面录制，不是 30/60 帧视频采集。单帧读取占用板卡与网口，测推理性能时请暂停镜像。页面暂停会保留最后一帧；传输失败会显示原因，不把旧画面标成实时。

## 数据口径

- 地块面积按当前场景 GSD² 换算；类别面积只累计多边形内当前任务已经接收的真实分类像素。
- 覆盖率 = 地块内已接收像素 / 地块像素。各类占比、主类占比、混杂比例和低置信占比的分母是已接收部分。未识别部分不外推。
- 单点探查不会增加地块的已识别面积。水体、道路等非作物类别仍保留。
- 地块统计由 PC 汇总并通过现有唯一 UDP 连接同步到板卡，校验启动、会话、任务、场景、权重和台账版本。历史任务不能覆盖当前 DP。PC 停止更新时保留最后统计并提示更新暂停。
- 芯片温度来自 PS SYSMON，只读当前值及本次启动峰值。PC 超过 3 秒没有有效样本会显示过期，不沿用旧值作为当前温度。这不是板上每个器件的温度。
- 功率和能耗仍显示“未接入测量”，没有用温度或推理时间估算功率。
