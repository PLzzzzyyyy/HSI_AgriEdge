## 2. 已说明的定位与流程，不必下轮从头重讲

- 定位：**面向无人机高光谱农田调查的 FPGA 边缘分类与农情核查辅助原型**；回答“种了什么、分布在哪里、占比多少、哪些位置值得人工复核”。不宣称已实飞、已接相机、实时全景、病害诊断、产量预测或自动施药。
- 主链：PC 离线准备 `.mat`/权重 → SD 文件 → PS 按需读取当前整景到 DDR → PS 7×7×270 取窗/逐窗归一化/CLS 与位置编码/int16 量化 → PL 12 层及分类头 → DDR 真实结果库 → PS 本地 DP 与 UDP 回传 PC。
- 以太网已用于网络接入/身份核验、任务控制、模型包下发与结果/状态回传；整景 `cube_f32.bin` 仍从 SD 加载到 DDR。网络触发加载不等于网络传输了 cube，网络接入也不等于 Vitis/JTAG 程序下载。
- 断网继续已获用户实机确认，但不代替“上电即用、无 PC 全流程”验收；GT 只用于评测。面积依赖有效 GSD/几何关系，低置信度只表示待核查，无地理参考时只报告行列坐标。
- 旧方案的 1 ms、数瓦、机载/落地即出图等目标不直接作为当前实测事实。比赛依据本地正式指南 §3.3，重点是应用价值、真实 FPGA 贡献、正确性与完整度、可复现性，不以功能数量论创新。
