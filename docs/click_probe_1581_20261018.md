## 使用

更新后 Ctrl+F5 刷新网页，选择“单点探查”或左侧“平移探查”，在图像内轻点像素，等待结果即可。拖动地图、框选和绘制地块不会触发。

同一已加载场景可直接探查；新场景首次高光谱输入准备仍可能耗时约 15～40 秒。本次改善点击交互和提交等待，不宣称 FPGA 计算速度提高一倍。
