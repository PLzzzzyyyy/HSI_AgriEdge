## 已完成的实际检查

- 原配套版本仍为 `build/host/gcs_click_probe_20261018_v7`，未改固件套件、START 入口、推理 IP 或生产运行源文件。
- 2026-10-21 本机 `127.0.0.1:8765` 没有服务监听；此状态不是 INA226 无响应的证据。
- XSDB 能枚举到板卡的 PS TAP、PMU、PL；只读 MIO24/25 均为 0。读取 I2C0 `0xff020000` 被硬件拒绝，报 `Blocked address ... Block level reset, bit 9 in RST_LPD_IOU2`。因此没有执行 I2C 事务，也没有读到传感器身份。
- 本次诊断没有停止 CPU、复位、下载 bit/ELF、改变 GPIO 输出或电源轨。原始诊断入口为 `tools/ina226_readonly_diagnostic.tcl`。
- 当前 XSA 中 I2C0 为 EMIO，I2C1 为 MIO24/25。HWH 顶层只有原风扇输出；现有 KEY6 ECO 另加 AF12 输入，并未为 J45/J46 引出 I2C。
- 厂商 AXU5EV-E 手册的 J45/J46 是通用 PL 扩展排针，两个接口第 2 针均为 +5V，第 39/40 针为 +3.3V，第 1/37/38 针为地。不能把“接口 2”或“第 2 针”当成已确认的 SDA/SCL。

## 已准备、离线通过的代码

独立目录 `src/ps/power_monitor/ina226.h/.cpp`，尚未接入生产 App、通信协议或 PC/DP 显示，不应表述为实时功率已实现或上板通过。

- 只允许通过显式适配的有界 I2C 回调访问已经确认的总线；不扫描未知 GPIO 或猜测引脚。
- 读取厂家/器件 ID；配置必须明确确认接线、分流电阻及模块电流上限。默认禁用。
- 触发式总线/分流电压测量，16 次平均、两通道各 1.1ms；前台非阻塞轮询，100ms 转换超时。读数完成后保持不再刷新，避免跨次转换混读。
- 从真实总线电压和分流电压计算电流、功率。按 TI 定义使用 1.25mV/bit 和 2.5µV/bit；软件以已确认的实际分流电阻计算 I 和 V×I，不依赖尚未校准的电流/功率寄存器。标记反向电流、饱和、超量程及读取失败。
- 任务能耗按真实相邻样本梯形积分。大于 300ms 的缺失区间、无效读数不外推，累计覆盖时间单独记录；停止后冻结，下一任务清零。任务起止的无样本边缘不补算，不能宣称完整任务能耗。
- `tools/tests/test_ina226.cpp` 已由 g++ C++14、`-Wall -Wextra -Werror` 编译并通过。输出位于 `report/ina226_20261021/test_ina226.exe`。验证了 12V/10mV/R010=1A/12W、R100 差异、错误 ID、缺少接线确认、反向、饱和、超时、缺样和任务隔离。

TI 数据手册：https://www.ti.com/lit/ds/symlink/ina226.pdf 。模块分流电阻、额定电流和接线不能由 INA226 器件 ID 自动读出。

## 继续实施需要的事实

1. 接口丝印（如 J45/J46）以及 VCC/GND/SDA/SCL 的实际针脚，需看清模块和排针照片。
2. 模块正面分流电阻标字、模块型号/电流额定值，及供电测量回路。模块逻辑电源和总线电平需与目标 Bank 匹配。
3. 要测整板输入功率，IN+/IN− 必须按模块电路串入整板输入正极。只连接四根 I2C/供电线不会得到整板电流。VBUS 接点也需按模块原理图核实。

事实齐全后：选择并约束两根明确的扩展 IO，按实际电路引出开漏 I2C；独立构建和验证硬件，接入采集/任务计时、带 boot/session/sample 身份的遥测与缺样标记，PC/DP 同步显示电压、电流、实时功率及测量覆盖充分的能耗，最后冻结配套套件并更新 START 的 deployment 清单。未知接线时不部署猜测引脚的位流。
