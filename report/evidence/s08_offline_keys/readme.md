# DP 离线按键与默认权重（2026-10-26）

已删除中央地图下“青框…”、GSD 数值与 GSD 说明。面积换算仍使用各场景真实 GSD。
启动时选龙口 V2 自训权重（CRC 27231983），在实际任务开始时加载和核验输入及模型；洪湖、汉川选择其各自已登记配套模型，不能跨景套用龙口权重。

## 按键

KEY7 仍为硬件复位，不改动。
KEY5 单击随机单点，双击整景巡检，长按 2 秒安全停止后切到下一场景。
KEY6 单击随机矩形，双击 3～5 顶点简单多边形及外接矩形识别，长按 2 秒切景。
25ms 消抖、350ms 多击判定、2s 长按判定保持原版。
随机矩形同时满足 6000 平方米物理面积上限与 4096 像素演示预算，避免小 GSD 场景意外启动极大区域。

## 离线执行

联网且后台在线时保留原 PC 联动。未检测到 PC 心跳时，前台接管实际按键，复用同一个 Runtime / 模型登记 / FPGA CLASS 推理入口。无假 UDP 主机、无 PC 推理补算。
一旦离线任务接管，迟到的 PC START、模型修改、按键收据不会重复创建或覆盖任务。正在运行时，额外巡检指令会被拒绝；长按可请求安全停止，在已提交行边界完成后切景。
离线多边形仅累计其内部实际 CLASS 像素，分别显示已识别覆盖、分类面积、占比及低置信比例，来源注明板端本地统计。

## 重连

离线任务结束后，重新接网线并在 PC“连接板卡”连接。先校验相同 boot / release / CRC 日志与空闲终端 INFO，再显式移交控制权，不隐式重启或恢复任务。
原 PC 任务历史与启动占用记录保留。离线结果继续留在 DP，直到新任务覆盖。离线本次任务在板端四个结果槽内保留；本版不把离线任务自动导入 PC 的历史列表。
运行中的本地任务不会被 PC 连接夺走；请先等完成或长按切景。

本次仅更新应用 ELF 与配套控制台；FPGA 位流和推理数值算法不变。START.bat 根据 deployment.json 选择新套件。未修改 SD 的启动镜像或启动拨码。

最终候选 v2 额外验证：当前场景已有健康任务时，离线单点复用其独立探查通道，可连续点击，不重置区域范围、像素数或多边形统计。


## 终端到 PC 的交接修复

- 交接时保留已结束的任务描述、完成前缀和能耗积分，避免任务 0 的包头中携带任务 N 的能耗。
- 无 PC 运行任务对象时，心跳和 DP 镜像仍使用实际保留的板端任务号。
- 已完成的独立探查交接后保持完成状态，顶栏恢复“待机”。
- v3 在真实板卡 boot 228ce129 完成实体单点后交接，模型目录、持续心跳、温度/功耗和实际 DP 镜像读取通过，106 条 PC 历史保持。
- 最终 v4 只补充独立探查交接后的完成显示分支；纯协议回归同时覆盖保留的能耗任务号、实际停止前缀和探查完成状态。
